About This Dictionary

A multi-discipline engineering standards reference for civil, structural, geotechnical, and architectural engineers. Covers Indonesian (SNI), American (ACI/AISC/ASCE/ASTM), and Chinese (GB/JGJ) standards.

Type a topic in plain language — concrete, steel, foundation, loads, or seismic — and the dictionary returns a comprehensive cross-standard answer module plus the relevant code cards. Add a project type (e.g. "power plant") and a location (e.g. "North Maluku") to get risk category, importance factor Ie, and regional seismic estimates.

The built-in knowledge base is derived from 80+ standards PDFs. Running build_index.ps1 expands the search to full extracted text from your local PDF collection (currently loaded: checking…).

📚 Add the PDF Library to GitHub (Manual Step)

The full-text search index (standards_data.js) is generated from your local PDFs, but the PDF files themselves are not committed automatically (they are large and excluded by .gitignore). To publish the actual PDFs so visitors can open them, add them manually with these terminal commands:

cd "C:\Users\cader\OneDrive\Desktop\Alexander\Engineering Standards Website"

# Create category subfolders for the PDFs
New-Item -ItemType Directory -Force standards/SNI, standards/American, standards/Chinese

# Copy your PDFs into the matching subfolders, then commit & push:
git add standards/
git commit -m "Add PDF library"
git push
Note: GitHub has a 100 MB per-file limit and recommends repositories stay under 1 GB. If the combined PDF library is very large, consider hosting the PDFs on a release asset, an external bucket, or Git LFS instead of committing them directly.

🚀 Deploy to GitHub Pages (Free Public Hosting)

1
Install Git and create a free account at github.com
2
Create a new repository named engineering-standards-dictionary and make it public
3
Run the index builder to extract PDF content: 
cd "C:\Users\cader\OneDrive\Desktop\Alexander\Engineering Standards Website"
.\build_index.ps1
4
Push the site to GitHub: 
git init
git add index.html standards_data.js
git commit -m "Initial deployment"
git remote add origin https://github.com/YOUR_USERNAME/engineering-standards-dictionary.git
git push -u origin main
5
Go to GitHub repo → Settings → Pages → Source: main branch → Save. Site will be live at https://YOUR_USERNAME.github.io/engineering-standards-dictionary/
6
To update after adding/removing PDFs: re-run build_index.ps1, then git add . ; git commit -m "Update index" ; git push
